# Meu Carro — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA "Meu Carro" para iPhone: o usuário anota o km diário, os abastecimentos e os gastos do Virtus, e vê km, consumo e custos por dia, semana e mês.

**Architecture:** Site estático (HTML/CSS/JS puro, ES modules, sem build) no GitHub Pages, com dados no Supabase (mesmo projeto do meu-treino, tabelas `carro_*` com RLS). Toda a matemática fica em `js/calc.js` (funções puras, testadas com `node --test`). O acesso a dados fica em `js/db.js` com fila offline (`js/fila.js`). Cada aba é um módulo em `js/telas/`.

**Tech Stack:** HTML/CSS/JS ES2022, `@supabase/supabase-js@2` via CDN (esm.sh), Chart.js 4 via CDN, Node 20+ `node:test` para testes, Playwright (Python) só para screenshots de verificação.

**Spec:** `docs/superpowers/specs/2026-11-24-meu-carro-design.md`

## Global Constraints

- Interface 100% em português do Brasil; números exibidos no formato pt-BR (`R$ 5,99`, `15,9 km/l`, `80.825 km`).
- Fuso fixo `America/Sao_Paulo` para decidir o "dia" de uma anotação.
- Sem framework, sem bundler, sem `npm install` no site publicado; dependências só via CDN.
- Tabelas com prefixo `carro_`, todas com `user_id uuid references auth.users` + RLS `user_id = auth.uid()`.
- Categorias padrão, nesta ordem: Revisão, Troca de roda, Troca de pneu, Modificações, Lavagem, Estacionamento, Outros.
- Combustíveis: `alcool`, `gasolina_comum`, `gasolina_aditivada` (rótulos: Álcool, Gasolina comum, Gasolina aditivada).
- Consumo: exato entre os 2 "tanque cheio" mais recentes; senão média longa de 60 dias (mínimo de 3 intervalos, Σkm ÷ Σlitros de A); menos de 2 abastecimentos → "calculando…"; menos de 4 intervalos na média longa → marcar "estimativa" (spec §8).
- Semana = segunda a domingo.
- Repositório `GabrielJaguati/meu-carro`, público, GitHub Pages na branch `main`, raiz.
- Visual: **mostrar opções em print ao Gabriel e esperar a escolha** antes de estilizar (Task 4).

## Review Focus

1. **km digitado errado** (ex.: `8082` em vez de `80825`, menor que a leitura anterior) → recusar com mensagem clara, sem salvar. *(Task 2)*
2. **Vírgula decimal e milhar pt-BR** (`5,99`, `80.825`, `R$ 100,00`) → aceitar e converter corretamente. *(Task 1)*
3. **Poucos dados** (0 ou 1 abastecimento, só uma leitura, divisão por zero) → mostrar "calculando…" ou "—", nunca `NaN`/`Infinity`. *(Tasks 1–2)*
4. **Anotação perto da meia-noite** (23h50 em Cachoeirinha = 02h50 UTC do dia seguinte) → grava o dia local. *(Task 1)*
5. **Salvar offline e reconectar** (ou tocar Salvar duas vezes) → nenhuma linha duplicada: o id é gerado no cliente (`crypto.randomUUID()`) e o envio faz `upsert`. *(Task 3)*

### Task 2: Cálculos de km, consumo e custos

**Files:**
- Modify: `js/calc.js`
- Test: `tests/calc.test.js`

**Interfaces:**
- Consumes: `periodo` (Task 1).
- Produces:
  - Tipos: `Leitura = {data: string, km: number}`; `Abastecimento = {data, km, valor, preco_litro, litros, combustivel, tanque_cheio: boolean}`; `Gasto = {data, valor, categoria_id}`
  - `validarLeitura(leituras: Leitura[], nova: Leitura): {ok: true} | {ok: false, erro: string}`
  - `kmPorDia(leituras: Leitura[], inicio: string, fim: string): {data: string, km: number}[]`. Cada dia do intervalo aparece; o salto entre leituras vizinhas é dividido igualmente entre os dias depois da primeira até a segunda, inclusive.
  - `kmRodados(leituras, inicio, fim): number` = soma de `kmPorDia`
  - `intervalosConsumo(abast: Abastecimento[]): {de, ate, km, litros, combustivel}[]` (A→B: km_B−km_A, litros de A, combustível de A)
  - `consumoMedio(abast, {combustivel?: string, dataRef: string, dias?: number = 60, minIntervalos?: number = 3}): {kmL: number, metodo: 'cheio'|'media', estimativa: boolean} | null` (spec §8, regras 1→3)
  - `gastoEstimadoDia(kmDia: number, kmL: number|null, preco: number|null): number | null`
  - `custoPorKm(total: number, km: number): number | null`
  - `compararCombustivel(precoAlcool, precoGasolina, kmLAlcool?, kmLGasolina?): {proporcao: number, limite: number, compensa: 'alcool'|'gasolina'}`. `limite` = kmLAlcool/kmLGasolina quando ambos existem, senão 0.7.
